# 🏠 MyKakeibo - 家計簿ウェブアプリ

自宅サーバーで動かすシンプルでモダンな家計簿ウェブアプリです。  
収支の記録・集計・グラフ分析・予算管理が一画面で行えます。

---

## 🚀 機能一覧

### ✅ 実装済み機能

| 機能 | 説明 |
|------|------|
| **ダッシュボード** | 月別の収入・支出・収支バランス、カテゴリ別支出ドーナツグラフ、6ヶ月推移グラフ、最近の取引を表示 |
| **収支一覧** | 取引一覧をページネーション付きで表示。種別・カテゴリ・キーワードでフィルタリング可能 |
| **収支入力** | 収入/支出の切替タブ、日付・金額・カテゴリ・メモを入力。カテゴリはカスタム追加対応 |
| **予算管理** | カテゴリ別に月次予算を設定。進捗バーで使用率を視覚的に確認 |
| **分析** | 12ヶ月収支棒グラフ、収入カテゴリ円グラフ、日別累積支出折れ線グラフ |
| **月切替** | ヘッダーの矢印ボタンで任意の月のデータを参照 |
| **レスポンシブデザイン** | PC・タブレット・スマートフォンに対応 |
| **サイドバー折りたたみ** | デスクトップでサイドバーをコンパクトに表示可能 |

### ❌ 未実装機能（推奨次ステップ）

- CSV エクスポート / インポート
- 複数ユーザー対応・ログイン機能
- 定期支出の自動登録
- 年次集計レポート
- カラーテーマ切替（ダークモード）
- プッシュ通知（予算超過アラート）

## 📊 データモデル

### `transactions` テーブル（収支データ）

| フィールド | 型 | 説明 |
|------------|-----|------|
| `id` | text | 一意識別子（自動生成） |
| `date` | text | 取引日 (YYYY-MM-DD) |
| `type` | text | `income`（収入）/ `expense`（支出） |
| `category` | text | カテゴリ名 |
| `amount` | number | 金額（円） |
| `memo` | text | メモ・備考 |

### `budgets` テーブル（予算データ）

| フィールド | 型 | 説明 |
|------------|-----|------|
| `id` | text | 一意識別子（自動生成） |
| `month` | text | 対象月 (YYYY-MM) |
| `category` | text | カテゴリ名 |
| `budget` | number | 予算金額（円） |
| `label` | text | 説明ラベル |

## 🔗 API エンドポイント

RESTful Table API を使用：

| メソッド | パス | 説明 |
|----------|------|------|
| `GET` | `tables/transactions` | 取引一覧取得 |
| `POST` | `tables/transactions` | 取引登録 |
| `PUT` | `tables/transactions/:id` | 取引更新 |
| `DELETE` | `tables/transactions/:id` | 取引削除 |
| `GET` | `tables/budgets` | 予算一覧取得 |
| `POST` | `tables/budgets` | 予算登録 |
| `PUT` | `tables/budgets/:id` | 予算更新 |
| `DELETE` | `tables/budgets/:id` | 予算削除 |

## 📅 デフォルトカテゴリ

**支出**: 食費、交通費、光熱費、通信費、日用品、医療費、娯楽、衣服、外食、教育、保険、住居、その他

**収入**: 給与、副業、ボーナス、投資、その他収入

> カテゴリは画面上からカスタム追加できます。

## 🔧 ローカル開発

```bash
# プロジェクトをクローンして静的サーバーで起動するだけ
# 例: Python 3
python3 -m http.server 8080

# または Node.js
npx serve .
```

ブラウザで `http://localhost:8080` を開いてください。
